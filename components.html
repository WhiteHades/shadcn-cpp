Components

The catalogue follows the stock shadcn component order. Each page maps the public name to a Qt widget, a native C++ example and the relevant ownership and accessibility notes.

The catalogue thumbnails are native Qt captures. Open a component page to use its interactive Qt WebAssembly preview and view the C++ example. The optional video player currently runs as a desktop example.
