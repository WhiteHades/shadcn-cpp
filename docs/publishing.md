# Clone and publish

The repository is [WhiteHades/shadcn-cpp](https://github.com/WhiteHades/shadcn-cpp). Version 0.1.0 identifies the current development series. Pin a commit when using it; there is no release tag.

```sh
git clone https://github.com/WhiteHades/shadcn-cpp.git
cd shadcn-cpp
```

After reviewing changes and running the [checks](testing.md), commit the intended files and push with `git push origin main`. Review the resulting GitHub Actions runs before changing any component's verification status.

## Initial repository creation

`bash tools/publish.sh --public` is a one-time setup command. It checks that GitHub CLI is signed in as WhiteHades, validates the project records, creates the repository and pushes the current history. It also sets the repository description and topics. It refuses an existing repository, an existing `origin` remote or uncommitted changes.

The supplied Git bundle preserves the initial commits. A bundle clone initially uses the bundle file as `origin`; that local remote must be removed before running the creation script. The original bundle should be retained as the source snapshot.

## Documentation

Docusaurus hosts the guides and the C++ API reference generated by clang-doc. Install Node.js 22, Python 3, CMake, Ninja, Clang, clang-doc and Qt 6.8 or later, then run `bash tools/build-docs.sh`. `CLANG_DOC` and `CXX` can select versioned Clang tools. The build uses the committed npm lockfile through `npm ci --ignore-scripts`.

To preview the built site, run `npm --prefix website run serve`. To edit the guides with live reload, first run `bash tools/generate-api.sh`, then `npm --prefix website start`. Regenerate the API pages after editing a public C++ header.

GitHub Pages is configured to use Actions. The manual `Publish documentation` workflow deploys the site to [whitehades.github.io/shadcn-cpp](https://whitehades.github.io/shadcn-cpp/). Run that workflow after changes to update the public documentation.
